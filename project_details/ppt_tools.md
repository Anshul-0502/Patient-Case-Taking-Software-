# 3. CORE PROJECT MESSAGE

The main value of this project must remain clear throughout the presentation.

The software is:

> An AI-assisted clinical case-taking system that collects patient history before physician consultation, digitizes previous medical documents, and generates a structured physician-ready patient report.

The software is NOT:

- An autonomous doctor
- A replacement for a physician
- An autonomous diagnosis system
- An autonomous prescription system
- An autonomous treatment recommendation engine

The doctor remains responsible for:

- Physical examination
- Clinical reasoning
- Diagnosis
- Prescription
- Treatment decisions

This safety principle must appear clearly in the presentation.
